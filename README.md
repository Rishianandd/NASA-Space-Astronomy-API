# EPITA Space & Astronomy

A Python package developed for EPITA Group 5 – Space & Astronomy.

The package retrieves live Astronomy Picture of the Day (APOD) information and provides access to NASA-related astronomy content.

## Features

- Retrieve the latest Astronomy Picture of the Day.
- Access astronomy information through a live API.
- Load API configuration securely using environment variables.

## Installation

Install the package using pip:

```bash
pip install epita-rishi-anand-space-astronomy
